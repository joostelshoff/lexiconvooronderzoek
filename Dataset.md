# Dataset

## Definitie
Een **dataset** is een samenhangende verzameling gegevens die als een herkenbaar geheel wordt beheerd, gebruikt, beschreven, gedeeld of gearchiveerd in de context van onderzoek.

## Gebruik in context  

### Beleid
In beleidscontext is een dataset een onderzoeksobject waarvoor eisen kunnen gelden rond kwaliteit, documentatie, opslag, toegankelijkheid, beveiliging, archivering en hergebruik.

### Administratie
In administratieve context wordt een dataset geregistreerd met kenmerken zoals titel, maker, versie, beschrijving, classificatie, opslaglocatie, toegangsvoorwaarden en eventuele PID.

### Informatiemodel / systeem
In informatiemodellen wordt een dataset gemodelleerd als informatieobject met relaties naar metadata, documentatie, project, opslagvoorziening, toegangsrechten en archief- of repositorysystemen.

## Afbakening
Een dataset is niet hetzelfde als:
- [[Metadata]]: de beschrijving van de dataset
- [[Datadocumentatie]]: aanvullende uitleg of context over de dataset
- [[Datamanagementplan]]: het plan voor omgang met data binnen een project

Een dataset kan persoonsgegevens bevatten, maar hoeft dat niet te doen.

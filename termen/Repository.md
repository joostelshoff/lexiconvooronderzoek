# Repository

## Definitie
Een **repository** is een digitale voorziening of beheerde opslagomgeving voor het vastleggen, beschrijven, bewaren, beschikbaar stellen en terugvindbaar maken van onderzoeksobjecten, zoals datasets, publicaties of andere kennisproducten.

## Gebruik in context  

### Beleid
In beleidscontext ondersteunt een repository de duurzame beschikbaarheid, vindbaarheid, toegankelijkheid en soms herbruikbaarheid van onderzoeksoutput en onderzoeksdata.

### Administratie
In administratieve context wordt een repository gebruikt voor registratie, opslag, beschrijving, publicatie of archivering van onderzoeksobjecten, inclusief metadata, toegangsrechten en eventuele persistente identificatoren.

### Informatiemodel / systeem
In informatiemodellen wordt een repository gemodelleerd als voorziening of systeem met relaties naar datasets, publicaties, metadata, PID’s, toegangsbeleid en bewaarbeleid.

## Afbakening
Een repository is niet hetzelfde als:
- [[Dataset]] of [[Publicatie]]: de objecten die in een repository kunnen worden opgenomen
- [[Metadata]]: de beschrijvende gegevens over die objecten
- [[Persistent Identifier (PID)]]: de identificator die aan objecten in een repository kan worden gekoppeld
- [[Archiveren]]: de activiteit of functie die via een repository ondersteund kan worden, maar daar niet volledig mee samenvalt

Niet elke opslagomgeving is automatisch een repository; het begrip veronderstelt doorgaans een zekere mate van beheer, beschrijving, ontsluiting en duurzame beschikbaarheid.
